# WebGL Minecraft 🌳
>Attempt to create basic minecraft functionality in three.js.
## How to run
Serve the folder with any static server (for example `npx serve .`) and open `index.html`.
## Features
 - Basic movement
 - Basic collision detection
 - Simple infinite terrain generation
 - Switching block type
 - Pointerlock
